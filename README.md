## 🎲 게임 개요

**Dicey Race**는 보드게임의 전략성과 러너 액션의 실시간 조작을 결합한 게임입니다.

플레이어는 매 턴 주사위와 카드 덱을 전략적으로 선택하고, 이동 중 점프, 슬라이드, 공격, 패링을 활용해 장애물과 적을 돌파하며 목적지까지 도달해야 합니다.

## 🎮 핵심 시스템 구현

### 1. 턴 기반 보드-러너 루프

- 턴 흐름을 `Mulligan → Standby → Move → End` 4단계로 분리하여 게임 진행을 구조화
- 턴 시작 시 카드 선택, 대기 구간에서 패시브 발동, 이동 구간에서 실시간 액션 입력이 이어지는 방식으로 설계
- 턴 종료 시 카드와 임시 효과를 정리하여 다음 턴 상태를 안정적으로 초기화

### 2. 주사위 및 카드 빌드 시스템

- 플레이어가 보유한 주사위를 기반으로 3D 주사위 굴림 결과를 계산해 이동 횟수를 결정
- 멀리건 시스템을 통해 매 턴 카드 4장을 확인하고, 액티브/패시브 카드 조합을 전략적으로 구성
- 카드 효과는 이동 증가, 돌진, 패링 강화, 장애물 파괴, 발판 효과 무시 등 다양한 방식으로 설계

### 3. 실시간 액션 상호작용

- 이동 중 `점프`, `슬라이드`, `공격`, `패링` 입력을 받아 장애물과 적의 공격에 대응
- 충돌 대상의 타입에 따라 회피, 파괴, 피격, 반사 피해 등의 결과가 달라지도록 처리
- 원거리 적 투사체, 장애물, 보스 공격과 같은 위협 요소를 동일한 플레이 흐름 안에서 상호작용하도록 구성

### 4. 스테이지 진행 및 상점 시스템

- 일반 스테이지와 보스 스테이지를 분리하고, 클리어 시 상점 씬을 경유하는 구조로 설계
- 상점에서는 보유하지 않은 카드와 주사위를 랜덤하게 노출하고, 재화를 사용해 빌드를 확장 가능
- 필드 진입 상태를 저장한 뒤 상점 복귀 후 동일한 진행 상태로 이어서 플레이할 수 있도록 구현

### 5. 진행 정보 및 시야 제어 UI

- 남은 이동 수, 리롤 수, 도착지까지의 거리, 보유 재화를 메인 UI에 실시간 반영
- 이동 시작 전 전체 맵 보기 기능을 통해 현재 위치와 스테이지 구성을 확인할 수 있도록 지원
- 튜토리얼 및 정보 패널을 별도 UI로 분리해 플레이 흐름을 방해하지 않도록 구성

## ⚙️ 트러블슈팅 및 최적화

**1. 상점 씬 이동 후 필드 복귀 시 플레이 상태가 초기화되는 문제**

- 상점 진입을 별도 씬 전환으로 처리하면서 플레이어 위치, 진행 거리, 남은 이동 수, 리롤 수, 보스 체력, 카드 효과 상태가 초기화되는 문제가 있었습니다.
- 필드 복귀에 필요한 값을 `FieldSceneState`로 통합 저장하고, 씬 복귀 직후 각 매니저가 동일한 상태를 기준으로 복원하도록 구조를 변경해 해결했습니다.

**2. 씬 전환 과정에서 GameManager가 중복 생성되어 전역 데이터가 꼬이는 문제**

- 씬 이동 중 `GameManager`가 중복 생성되면 코인, 카드, 주사위, 체력 등 전역 데이터가 초기값과 섞이며 상태가 불안정해지는 문제가 있었습니다.
- `DontDestroyOnLoad` 기반 싱글톤 구조를 고정하고, 중복 인스턴스를 즉시 제거하도록 수정해 전역 상태를 안정적으로 관리했습니다.

**3. 주사위 굴림 후 자동 이동 대기 구간에서 입력이 충돌하는 문제**

- 주사위 결과가 확정된 뒤 자동 이동이 시작되기 전, 버튼 입력이나 전체 맵 보기 전환이 겹치면 이동이 중복 실행되거나 의도치 않게 시작되는 문제가 있었습니다.
- 이동 대기 상태를 별도 플래그로 분리하고, 예약된 코루틴을 취소 및 재등록할 수 있게 구성해 입력 충돌을 방지했습니다.

**4. 카드 효과와 타일 효과가 동시에 이동 값을 수정하며 진행도가 어긋나는 문제**

- 카드, 타일, 피격 보정이 모두 이동에 관여하다 보니 실제 진행도와 UI에 표시되는 남은 이동 수가 서로 다르게 반영되는 문제가 있었습니다.
- 효과 처리 로직을 `EffectProcessor`로 일원화하고, 상황에 따라 `remainingMoves`와 `stageDistance`를 분리 갱신하도록 수정해 턴 흐름과 진행도를 일치시켰습니다.
